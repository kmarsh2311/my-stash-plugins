# FastTag terminology

Use these terms when discussing FastTag with the user:

- **Console** means the main part of an editor popup: Edit Tags console, Edit Performers console, Edit Studio console, Edit Galleries console, or Edit Everything console.
- **HUD** means a supporting pop-out or floating tool: Cover Editor HUD, Scraper HUD, or Video HUD.

For example: “The Scraper HUD should fade with the Edit Everything console.”
